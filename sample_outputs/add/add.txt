  1. Explaining a wrong answer to the student
     Example: add.c prints -2147483648 for the input 2147483647 1. The
     report shows the input, the expected 2147483648, what the program
     printed, and says to use long long.
     Benefit: The student sees exactly which input breaks the program

     Example: add_copy.c is add_good.c with every name changed. The
     agent still finds a similarity of 1.00 and raises a flag.
     Benefit: The teacher checks only the flagged pairs instead of every
     submission.
Limits of this report:
  1. Short programs look copied even when they are not
     Example: add.c has a similarity of 1.00 with an answer from the
     qwen LLM, because the obvious 5-line solution is the same for
     everyone.
     Fix: A flag never lowers the grade; the teacher decides.
  2. The readability score is the opinion of an LLM
     Example: add_syntax_error.c is neatly written but got 3/10 for one
     missing ';', while the more cramped add.c got 6/10.
     Fix: Readability is only 10% of the grade, and answers are cached
     so the score does not change between runs.
